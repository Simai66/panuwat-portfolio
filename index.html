About Me

เกี่ยวกับฉัน

ผมชื่อ ภาณุวัฒน์ เวยรัมย์ (Panuwat Woeiram) นักศึกษาชั้นปีที่ 4 สาขาวิทยาการคอมพิวเตอร์และนวัตกรรมข้อมูล มีประสบการณ์พัฒนา Web Application และระบบ IoT จากโครงการด้าน Software, Automation และ Data Integration โดยใช้ React, Next.js, TypeScript, Tailwind CSS, Supabase, ESP32 และ Raspberry Pi

มีประสบการณ์ตั้งแต่การออกแบบโครงสร้างระบบ พัฒนา Frontend เชื่อมต่อฐานข้อมูลและ API ไปจนถึงการนำระบบขึ้นใช้งานจริง รวมถึงการทำงานร่วมกับ Hardware, Sensor, MQTT และ Dashboard สำหรับระบบ IoT

สนใจพัฒนาต่อยอดในสาย Frontend Development, Software Development และ IoT โดยให้ความสำคัญกับโครงสร้างระบบที่ดูแลต่อได้ การออกแบบ UI ที่ใช้งานง่าย และการพัฒนาระบบที่สามารถนำไปใช้งานได้จริง
